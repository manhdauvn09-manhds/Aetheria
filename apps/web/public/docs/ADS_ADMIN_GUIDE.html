🎮 Aetheria — Admin Quảng cáo

Hướng dẫn kích hoạt hệ thống quảng cáo (Ads System)

📋 Tổng quan

Hệ thống quảng cáo Aetheria được thiết kế để:

  • Hiển thị quảng cáo sau khi người chơi hoàn thành level
  • Không làm gián đoạn gameplay (chỉ hiển thị ở màn kết thúc)
  • Dễ dàng bật/tắt qua Database (không cần deploy code)
  • Hỗ trợ nhiều nhà cung cấp quảng cáo (Google AdMob, custom API, ...)

🔄 Kiến trúc hệ thống

Quảng cáo được điều khiển bởi Feature Flag lưu trong Database:

Database: featureFlag table Key: "ads.enabled" Value: { "enabled": true, "provider": "admob", "placementId": "ca-app-pub-xxxxxxxxxxxxxxxx/yyyyyyyyyy", "durationSec": 15 }

Khi bạn update Database, hệ thống tự động sử dụng cấu hình mới (không cần restart).

🚀 Các bước kích hoạt quảng cáo

1 Chuẩn bị Ad Provider Account

Đăng ký tài khoản với nhà cung cấp quảng cáo:

  • Google AdMob: https://admob.google.com
  • Custom API: Nếu dùng server riêng

Cần lấy: App ID, Placement ID (hoặc Ad Unit ID)

2 Lấy Placement ID từ Ad Provider

Trong AdMob dashboard:

  1. Apps → Chọn app Aetheria
  2. Ad Units → Tạo "Interstitial" unit (loại quảng cáo full-screen)
  3. Copy Ad Unit ID (ví dụ: ca-app-pub-xxxxxxxx/zzzzzzzz)
3 Update Feature Flag trong Database

Truy cập Database (MySQL):

INSERT INTO featureFlag (key, value, updatedBy, updatedAt) VALUES ( 'ads.enabled', '{"enabled":true,"provider":"admob","placementId":"ca-app-pub-xxxxxxxx/zzzzzzzz","durationSec":15}', 'admin_user_id', NOW() ) ON DUPLICATE KEY UPDATE value = VALUES(value), updatedBy = VALUES(updatedBy), updatedAt = VALUES(updatedAt);

Thay thế:

  • ca-app-pub-xxxxxxxx/zzzzzzzz → Placement ID từ AdMob
  • admin_user_id → ID admin đang setup (tùy chọn)
  • durationSec → Thời gian hiển thị (10-20 giây khuyến nghị)
4 Xác minh quảng cáo hoạt động

Sau khi update Database:

  1. Đợi 1-5 phút (cache refresh)
  2. Vào game, hoàn thành 1 level
  3. Quan sát màn hình kết thúc → Nên thấy quảng cáo
  4. Check Admin Panel → /admin.cacheMetrics để monitor cache hits

📊 Database Config Reference

Bảng featureFlag lưu cấu hình:

Trường Kiểu Ví dụ Ghi chú
key VARCHAR ads.enabled Tên flag (không đổi)
value JSON {"enabled":true,...} Config JSON
enabled Boolean true Bật/tắt quảng cáo
provider String admob Nhà cung cấp
placementId String ca-app-pub-xxx/yyy ID từ Ad Provider
durationSec Number 15 Thời gian hiển thị (giây)
updatedBy BIGINT 12345 User ID admin (audit)
updatedAt TIMESTAMP 2024-01-15 10:30:00 Thời gian update

⚙️ Cách tắt/bật nhanh

Tắt quảng cáo ngay lập tức:

UPDATE featureFlag SET value = '{"enabled":false}' WHERE key = 'ads.enabled';

Bật lại:

UPDATE featureFlag SET value = '{"enabled":true,"provider":"admob","placementId":"YOUR_PLACEMENT_ID","durationSec":15}' WHERE key = 'ads.enabled';

Lưu ý: Thay đổi có hiệu lực sau 1-5 phút (cache refresh tự động).

🔧 Troubleshooting

❌ Vẫn không thấy quảng cáo sau update DB

Cách kiểm tra:
  • Kiểm tra featureFlag table: SELECT * FROM featureFlag WHERE key = 'ads.enabled';
  • Đợi 5 phút rồi reload game
  • Mở Dev Console (F12) → Check console errors
  • Kiểm tra admin panel metrics: /admin.cacheMetrics

❌ Quảng cáo không tắt được (vẫn hiển thị sau khi set enabled=false)

Giải pháp:
  • Cache có thể chưa refresh → Đợi 5 phút
  • Hoặc bạn đổi placementId để force reset cache
  • Trong trường hợp khẩn cấp: Restart API server

❌ AdMob không hiển thị quảng cáo thật

Nguyên nhân:
  • Placement ID sai → Kiểm tra lại ở AdMob dashboard
  • App chưa publish → Mới tạo app cần 24h để AdMob approve
  • Test mode → Cần publish app trước

💡 Best Practices

  • Test với quảng cáo tắt (enabled=false) trước khi bật
  • Bắt đầu với durationSec=10 (nhỏ để không làm phiền user)
  • Tăng dần (15, 20 giây) dựa trên feedback người chơi
  • Theo dõi CTR (click-through rate) trong AdMob dashboard
  • Không bắt buộc user xem (cho nút "Close Ad" để skip)
  • Audit log tự động ghi lại khi ai update flag (check table: auditLog)

📞 Cần hỗ trợ?

Nếu gặp vấn đề:

  1. Check auditLog để xem lịch update flag
  2. Xem Admin Panel → /admin.cacheMetrics để monitor system
  3. Restart API server nếu cần reset cache ngay lập tức
  4. Liên hệ dev team với thông tin error từ browser console
